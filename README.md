## პროექტის აღწერა

ეს არის ერთგვერდიანი (single-page) პორტფოლიო ვებსაიტი. გვერდს აქვს ზედა ნავიგაცია, რომლის საშუალებითაც მომხმარებელი შეუფერხებლად გადადის სხვადასხვა სექციაზე. დიზაინი მუქი თემისაა, მარტივი და სუფთა, ხოლო ყველა ფერი ერთ ადგილას, CSS ცვლადებშია გაწერილი, რაც მის მორგებას აადვილებს.

პროექტი განკუთვნილია დამწყებებისთვის და კარგად გამოდგება როგორც სასწავლო ნიმუში, ასევე როგორც საფუძველი რეალური პორტფოლიოსთვის.

## მიზანი

- წარმოადგინოს ავტორი და მისი უნარები;
- აჩვენოს შესრულებული პროექტები ბარათების სახით;
- მისცეს დაინტერესებულ პირს საკონტაქტო ინფორმაცია;
- იყოს მარტივად გასაგები და შესაცვლელი სასწავლო პროექტი.

## ფუნქციონალი

- **წებოვანი (sticky) ნავიგაცია:** მენიუ ყოველთვის ჩანს გვერდის ზედა ნაწილში;
- **გლუვი სქროლი:** მენიუს ბმულზე დაჭერისას გვერდი სათანადო სექციამდე გლუვად ეშვება;
- **პროექტების ბარათები:** პროექტები განლაგებულია ადაპტური grid-ით, ხოლო მაუსის მიტანისას ბარათი ოდნავ აიწევა;
- **უნარების სია:** ტექნოლოგიები ნაჩვენებია პატარა ბეჯების სახით;
- **ავტომატური წელი footer-ში:** JavaScript ავტომატურად სვამს მიმდინარე წელს;
- **Responsive დიზაინი:** გვერდი კარგად გამოიყურება კომპიუტერზე, ტაბლეტსა და ტელეფონზე.

## გამოყენებული ტექნოლოგიები

| ტექნოლოგია | დანიშნულება |
|------------|-------------|
| HTML5 | გვერდის სტრუქტურა და სემანტიკური ელემენტები |
| CSS3 | სტილები, Flexbox, Grid, CSS ცვლადები, ანიმაციები |
| JavaScript (ES6) | დინამიკური ელემენტები (მიმდინარე წელი) |
| Git | ვერსიების კონტროლი |

გარე დამოკიდებულებები (dependencies) არ არსებობს, ამიტომ პროექტს არ სჭირდება ინსტალაცია ან build ეტაპი.

## პროექტის სტრუქტურა

```
portfolio/
├── index.html    # მთავარი გვერდი და მისი სტრუქტურა
├── style.css     # ყველა სტილი და ფერები
├── script.js     # JavaScript ლოგიკა
├── README.md     # პროექტის დოკუმენტაცია
└── .gitignore    # Git-ის მიერ იგნორირებული ფაილები
```

### ფაილების აღწერა

- **`index.html`:** შეიცავს header-ს, ოთხ სექციას (მთავარი, ჩემ შესახებ, პროექტები, კონტაქტი) და footer-ს;
- **`style.css`:** აღწერს ფერებს, ტიპოგრაფიას, განლაგებას, ბარათებისა და ღილაკების სტილს და მობილური ეკრანის წესებს;
- **`script.js`:** ავსებს footer-ში მიმდინარე წელს;
- **`.gitignore`:** გამორიცხავს Git-იდან დროებით, სისტემურ და გარემოს ფაილებს (`node_modules`, `.env`, `.DS_Store` და ა.შ.).

## გვერდის სექციები

1. **Header / Navigation:** ლოგო და ბმულები სექციებზე გადასასვლელად.
2. **Hero (მთავარი):** მისალმება, მოკლე წარდგენა და ღილაკი „ჩემი პროექტები".
3. **About (ჩემ შესახებ):** მოკლე ტექსტი ავტორის შესახებ და უნარების სია.
4. **Projects (პროექტები):** სამი პროექტის ბარათი სათაურითა და აღწერით.
5. **Contact (კონტაქტი):** ელფოსტის ბმული.
6. **Footer:** საავტორო უფლებების ტექსტი და მიმდინარე წელი.

## გაშვების ინსტრუქცია

### ვარიანტი 1: პირდაპირ ბრაუზერში

1. გადმოწერე ან დააკოპირე `portfolio` ფოლდერი.
2. ორჯერ დააჭირე `index.html`-ს, ან გახსენი იგი ბრაუზერში.

### ვარიანტი 2: ლოკალური სერვერით

თუ კომპიუტერზე დაყენებულია Python:

```bash
cd portfolio
python -m http.server 8000
```

შემდეგ ბრაუზერში გახსენი: `http://localhost:8000`

### ვარიანტი 3: VS Code-ით

დააყენე **Live Server** გაფართოება, დააწკაპუნე `index.html`-ზე მარჯვენა ღილაკით და აირჩიე **Open with Live Server**.

## მორგება

### ტექსტის შეცვლა

გახსენი `index.html` და შეცვალე:

- სახელი `<h1>` და `.logo` ელემენტებში;
- აღწერა „ჩემ შესახებ" სექციაში;
- პროექტების სათაურები და აღწერები (`<article class="card">`);
- ელფოსტა `mailto:` ბმულში (`your@email.com`).

### ახალი პროექტის დამატება

დააკოპირე ბარათი `index.html`-ში და შეცვალე ტექსტი:

```html
<article class="card">
  <h3>პროექტის სახელი</h3>
  <p>პროექტის მოკლე აღწერა.</p>
</article>
```

### ფერების შეცვლა

გახსენი `style.css` და შეცვალე ცვლადები ფაილის თავში:

```css
:root {
  --bg: #0f172a;       /* ფონი */
  --surface: #1e293b;  /* ბარათების ფონი */
  --text: #e2e8f0;     /* ძირითადი ტექსტი */
  --muted: #94a3b8;    /* მეორეხარისხოვანი ტექსტი */
  --accent: #38bdf8;   /* აქცენტის ფერი */
}
```

### უნარების დამატება

დაამატე ახალი `<li>` ელემენტი `.skills` სიაში:

```html
<li>Python</li>
```

## Responsive დიზაინი

- პროექტების ბარათები განლაგებულია `grid`-ით (`auto-fit`, `minmax`), ამიტომ ეკრანის ზომის მიხედვით ავტომატურად იცვლება სვეტების რაოდენობა;
- სათაურის ზომა მოქნილია (`clamp()`);
- 600px-ზე ვიწრო ეკრანებზე ნავიგაციის ბმულებს ერთმანეთს შორის დაცილება და შრიფტი ეცვლებათ.
